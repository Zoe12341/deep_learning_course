1. Foundation

For a function with several inputs, a partial derivative changes one input while holding the others at their current values.

Function
z = f(x, y)
One output depends on two independent variables.
Partial derivative
∂f/∂x
Change x slightly while treating y as a constant.
Gradient
∇f = [∂f/∂x, ∂f/∂y]
The vector points in the direction of steepest local increase.
Important: “Hold y constant” does not mean set y to zero. It means keep y at its current value while x changes.

3. Example 2 — Partial derivatives of model loss

A linear model predicts p = wt + b for four data points. Mean squared error measures its performance.

L(w,b) = (1/N) Σ (wtᵢ + b − cᵢ)²
∂L/∂w = (2/N) Σ (pᵢ − cᵢ)tᵢ    |    ∂L/∂b = (2/N) Σ (pᵢ − cᵢ)

Why does ∂L/∂w contain tᵢ? By the chain rule, ∂p/∂w = tᵢ. Large inputs can therefore create large weight gradients—one reason normalization matters.

5. Quick practice

For f(x,y) = 4x³y + 2y², what is ∂f/∂x?

Reasoning: Hold y constant. The derivative of 4x³y is 12x²y. The term 2y² contains no x, so its partial derivative with respect to x is zero.
